Qué es el neoíbero

El neoíbero es una lengua construida que toma inspiración en el ibero histórico, pero no pretende ser una reconstrucción exacta. Se trata de un sistema lingüístico diseñado con coherencia interna, que busca ser usable, expresivo y reconocible.

Su objetivo no es replicar el ibero original, sino crear una lengua plausible, inspirada y estructurada, que permita explorar cómo podría haber evolucionado o sistematizado ese sustrato lingüístico.

Cómo funciona

El neoíbero se basa en un sistema de raíces y sufijos que permiten construir significado de forma consistente. La lengua tiende a un orden estructurado y a una morfología clara.

Algunos rasgos clave:

  • Uso de sufijos para marcar función y relación
  • Sistema derivativo coherente
  • Orden sintáctico estable
  • Inspiración fonológica en el ibero

El proyecto incluirá un libro de aprendizaje progresivo, pensado para entender el idioma desde cero de forma clara y práctica.
